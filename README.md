# FrameFlow Studio

Україномовний прототип персональної студії для створення YouTube Shorts, TikTok-роликів і кінематографічних відео. Інтерфейс підготовлено як основу для майбутнього підключення локальних AI-моделей, GPU-рендерингу, озвучення та експорту.

## Запуск у Visual Studio / VS Code

1. Відкрийте папку проєкту.
2. У терміналі виконайте `npm run dev`.
3. Відкрийте `http://localhost:4173`.

Залежності встановлювати не потрібно. Для production-збірки виконайте `npm run build` — готові файли з'являться в `dist`.

## Що вже працює

- перемикання між YouTube Shorts, TikTok і форматом кіно;
- автоматичний вибір співвідношення сторін 9:16 або 16:9;
- тривалість від 15 секунд до однієї години та якість до 4K;
- генератор ідей і перенесення готової концепції в промпт;
- інтерактивна симуляція черги локального рендерингу;
- адаптована панель проєктів, GPU-статусу й трендових концепцій.

> Поточна версія є UX-прототипом. Реальну генерацію відео слід підключити через локальний API (наприклад, ComfyUI/Stable Video), а фінальне складання — через FFmpeg або Remotion.
